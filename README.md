# SpacePulse Frontend

Single Page Application (SPA) para SpacePulse construida con Angular 18, Clean Architecture, Angular Signals y Angular Material.

## Inicio Rapido

```bash
npm install --legacy-peer-deps
npm start
```

Aplicacion disponible en: http://localhost:4200/

## Compilacion de Produccion

```bash
npm run build
```
